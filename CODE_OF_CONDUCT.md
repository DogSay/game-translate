# Code of Conduct

Be respectful, constructive, and patient. Discuss technical decisions without
attacking people. Harassment, discriminatory language, threats, doxxing, and
publishing another person's private data are not acceptable.

Maintainers may edit or remove contributions and interactions that violate
these expectations. Serious or repeated violations may result in a ban from
project spaces. Report conduct concerns privately through the maintainer's
GitHub profile or repository moderation tools.
